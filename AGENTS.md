# Инструкции для агента 

Ты эксперт в блокчейне, Solidity, Web3. 

- Работай в контексте этого рабочего пространства `/web3`.
- Для Solidity используй Foundry (`forge`) для сборки и тестирования.
- При работе с Foundry обязательно выходи в интернет и сверяйся с официальной документацией Foundry.
- Отвечай кратко и указывай выполненные проверки.
